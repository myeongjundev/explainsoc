## 페르소나 A — 보안관제 팀장, PoC를 처음 맡음 (데스크톱)

관제 5년차. 공급자가 준 "탐지율 99%" 자료를 들고 있다. ML 용어(Recall, Macro F1)는 들어 본 정도.

| 관찰할 곳 | 본 것 |
|---|---|
| "논문 예시로 60초 검토"의 의미 | 제목 "그 99%, 무엇을 시험한 점수입니까?"와 도움 문장으로 "공급자 성능표를 의심해 보는 도구"는 잡힌다. 버튼이 "예시를 보여 준다"는 것은 이해하지만 **"60초"가 무엇을 약속하는지는 화면에 설명이 없다** |
| 질문 상태·메모 발견 | 오른쪽 칸을 2화면 내려야 나온다. 안내 문장 "PoC 자리에서 질문하고, 받은 답과 다음 행동을 바로 남기세요"가 있어 발견하면 용도는 바로 안다. 왼쪽 칸(뒤집기·기준선·지도)을 먼저 읽는 사람은 오른쪽 아래를 늦게 본다 |
| 검토표 전체 복사가 최종 산출물인지 | "최종 산출물" 표시와 "받은 주장, 빠진 근거, 공급자 답변을 한 장으로 가져갑니다"가 있어 이해한다. 다만 위에 **"질문만 복사"가 먼저 나와** 그걸 누르고 끝낼 가능성이 있다 |
| 막힐 곳 | 앞면 "겉으로는 무난해 보이는 성능 주장 — 정확도 0.6299 · 오탐률 0.0002"에서 "0.63이 무난한가?"에 잠깐 멈출 수 있다. 오탐률 쪽이 핵심이라는 것은 뒤집은 뒤에야 보인다 |
| 한 줄(가상) | "공급자 숫자를 받았을 때 뭘 물어야 하는지 정리해 주는 도구" |

## 페르소나 B — 정보보호 부서 신입, 구매 검토 보조 (데스크톱)

비전공에 가깝다. 지시받은 대로 "처음 써 보기"만 한다. 버튼 이름을 글자 그대로 읽는다.

| 관찰할 곳 | 본 것 |
|---|---|
| "60초 검토"의 의미 | **타이머나 제한 시간으로 읽을 위험이 가장 크다.** 누른 뒤 시계가 없고 곧바로 3단계라, "1·2단계는 언제 하지?"라며 위쪽 단계 표시를 누를 수 있다. 작업대 안내("논문 예시 A — 숫자와 세 평가 조건을 논문 값으로 미리 채웠습니다")를 읽으면 풀린다 |
| 질문 상태·메모 | 선택 상자의 기본값 "아직 묻지 않음"을 **이미 정해진 결과**로 읽고 바꾸지 않을 수 있다. 메모 칸은 예시 문구가 있어 눈에 띈다 |
| 검토표 전체 복사 | "모델 품질 판정표가 아닙니다" 문장이 오히려 "그럼 이게 뭐지?"를 부를 수 있다. "인쇄·PDF 저장"을 최종 행동으로 고를 수도 있다(이것도 정답에 가깝다) |
| 막힐 곳 | 단위(TN·FP·FN·TP, Recall)가 풀이 없이 이어지는 "입력한 값" 표 |
| 한 줄(가상) | "AI 보안 제품 점수가 진짜인지 확인하는 체크리스트 같다" |

## 페르소나 C — ML 엔지니어 출신 PM, 이동 중 휴대폰 (모바일)

혼동행렬은 익숙하다. 비판적으로 읽고, 스크롤을 많이 하지 않는다.

| 관찰할 곳 | 본 것 |
|---|---|
| "60초 검토"의 의미 | 첫 화면의 "0.9979 대 0.3871" 막대 두 개로 **분할 차이가 핵심이라는 것을 가장 빨리 잡는다.** 60초는 "빠른 데모"로 읽는다 |
| 질문 상태·메모 | 모바일에서 4.4화면 아래다. 뒤집기·기준선·지도·판독 카드를 지나야 나온다. **스크롤을 멈추면 못 찾는다** |
| 검토표 전체 복사 | 5.5화면 아래. 제목 "그 99%"와 예시 앞면 "정확도 0.6299"가 달라 "99%는 어디 있지?"라는 질문이 나올 수 있다(99%는 첫 화면 오른쪽의 무작위 분할 0.9979, 앞면에는 오탐률 0.0002로만 있다) |
| 막힐 곳 | "검토 진행 지도"라는 이름과 "평가 조건 확인" 버튼의 관계. 이미 채워진 예시에서 그 버튼을 누르면 2단계로 돌아가는지 알기 어렵다 |
| 한 줄(가상) | "벤더 성능표에서 분할·미관측 공격 시험을 캐묻게 만드는 작업대" |

## 60초 경로 추정 (사람 측정 아님)

경로: 첫 화면 → "논문 예시로 60초 검토" → "공격 기준으로 뒤집기" → 검토 진행 지도 → 공급자 질문

| 가정 | 읽기 | 클릭·스크롤 | 합계 |
|---|---|---|---|
| 빠르게 훑음(분당 900자), 기준선 설명 건너뜀 | 약 34초 | 약 8초 | **약 42초** |
| 보통(분당 600자), 기준선 설명 건너뜀 | 약 51초 | 약 8초 | **약 59초** |
| 보통, 기준선 설명까지 읽음 | 약 77초 | 약 8초 | **약 85초** |

**60초는 기준선 설명을 건너뛸 때만 여유 없이 맞는다.** 사람 시험에서 가장 먼저 볼 것은 기준선 설명에서
멈추는지다.

## 사람 시험에서 지켜볼 곳

1. "60초"를 시간 제한으로 읽는지, 누른 뒤 1·2단계를 찾아 위로 가는지
2. 오른쪽 칸(데스크톱) / 4화면 아래(모바일)의 답변 상태·메모를 스스로 찾는지
3. "질문만 복사"에서 멈추는지, "검토표 전체 복사"까지 가는지. 복사한 글을 붙여 넣어 상태·메모가 들어갔는지
4. 뒤집은 뒤 "항상 정상 기준선" 설명에서 몇 초 쓰는지 — 60초를 넘기는 주된 곳
5. "99%"와 "0.6299"의 차이를 묻는지
